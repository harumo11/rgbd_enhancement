# rgbd_enhancement



This repository is for research of depth enhancement.



## Installation

**Warn** The following installation command will install datasets and models. They are may heavy. Take care your PC disk usage.

```
git clone git@github.com:harumo11/rgbd_enhancement.git
```

```sh
sudo apt install aria2c
```



## Directory structure

| Directory      | Description                                                |
| -------------- | ---------------------------------------------------------- |
| `configs`      | Experiment configurations                                  |
| `data`         | Dataset such as DREDS, TransCG, Hand-Surface, etc.         |
| `src/datasets` | Classes to provide unified interfaces to different dataset |
| `src/models`   | Classes to definition of model architecture                |
| `src/metrics`  | Classes of MAE, RMSE, etc.                                 |
| `src/utils`    | Classes of common functions for train, validation, test    |
| `tools`        | Entry point of execute experiment                          |
| `third_party`  | Other great researches, such as Lingbot                    |
| `runs`         | Log of experiments                                         |
| `notebooks`    | Jupyter notebook                                           |
| `reports`      | Experiment results that is described by figures            |


## Datasets

Each dataset is Too heavy. For example, train dataset of DREDS has 71GBx5.
It takes a long time. So I use `aria2c` to parallel download.

As my experience, DREDDS-CatKnown train part 0 takes 5 hours to download.

- [DREDS](https://pku-epic.github.io/DREDS/?utm_source=chatgpt.com) : Depth dataset that generated by simulation. It contains ground truth.
    - [DREDS-CatKnown](https://mirrors.pku.edu.cn/dl-release/DREDS_ECCV2022/data/DREDS-CatKnown/)
    - [DREDS-CatNovel](https://mirrors.pku.edu.cn/dl-release/DREDS_ECCV2022/data/DREDS-CatNovel/) 
- [TransCG](https://graspnet.net/transcg?utm_source=chatgpt.com) : This dataset contains depth images that include transparent objects.
- [D405 Hand-Surface Depth Dataset](https://huggingface.co/datasets/muxiddin19/d405-hand-surface-depth?utm_source=chatgpt.com) : This dataset contains pairs of RGB and depth image. Images are captured by Realsense D405.



## Recording rules for experiments

In `runs` directory, 

- One directory, one experiment record.
- Directory name should be `NUMBER_MODELNAME_FEATURE`. For example `003_toy_unet`.
- One directory has `cofig.yaml`, `best.pth`, `metrics.json`, `predictions`.
